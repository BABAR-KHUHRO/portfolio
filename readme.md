## 🚀 Setup & Deployment

### Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://babar-khuhro.github.io/portfolio/
   ```

2. **Navigate into the project directory:**
   ```bash
   cd portfolio
   ```

3. **Open `index.html`:**
   - Simply double-click `index.html` to open it in any web browser.
   - Alternatively, use an extension like **Live Server** in VS Code for real-time live previewing.

---

### Deploying to GitHub Pages

Since GitHub Pages serves static files natively, follow these steps to deploy your site live:

1. Push your latest code updates to your primary repository branch (e.g., `main`):
   ```bash
   git add .
   git commit -m "Build: finalize dynamic site into static portfolio"
   git push origin main
   ```

2. Open your repository on **GitHub.com**.
3. Go to **Settings** > **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source:** Select `Deploy from a branch`.
   - **Branch:** Select `main` (or `master`) and `/ (root)`.
5. Click **Save**.
6. Wait 1–2 minutes, and your live URL will be accessible at:
   `https://<your-username>.github.io/<your-repo-name>/`

3. **Configure Contact Links:** Ensure email addresses, LinkedIn, and GitHub profile URLs point to your accounts.
